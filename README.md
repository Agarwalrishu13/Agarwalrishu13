### AI from the transistors up

Not calling APIs — building the stack underneath them:

- ⚙️ **[nanollama.c](https://github.com/Agarwalrishu13/nanollama.c)** — an LLM inference engine in ~1,400 lines of dependency-free C: transformer forward pass, BPE tokenizer, hand-rolled thread pool, int8 quantization. No BLAS, no OpenMP, no API keys.
- 🧬 **[nanobrain](https://github.com/Agarwalrishu13/nanobrain)** — a Llama-2 transformer trained from scratch in raw PyTorch (16.9M params, 35 hours on CPU), exported to my own engine's binary format.
- 🏗 **[nanoforge](https://github.com/Agarwalrishu13/nanoforge)** · 🎯 **[nanorl](https://github.com/Agarwalrishu13/nanorl)** — the studio and the SFT/DPO alignment trainers that complete the pipeline.
